## Reproduction Steps
**Preconditions**: Worker unreachable (hung or offline); guest in the hall

1. Open http://127.0.0.1:5174/?autoenter&at=bazaar with the Worker not answering
2. Tap 🛒 (Market) inside the Market, or 📖 (Rescue Book)

**Expected Result**: After a few seconds: an error line with Retry; the guest Market Cup text and "Log in with NEAR to play the Market Cup" lock button still shown (they need no prices)
**Actual Result**: "Loading prices…" / "Loading…" shown forever; no lock button, no Cup text, no error

## Technical Context
- **Likely affected files**: src/near/index.ts (loadMarket: fetch without timeout; openBook waits for a 'book' socket reply that never comes)
- **Related systems**: —
- **Possible root cause / fix idea**: Add a timeout (AbortController ~6 s) and an error state with Retry; render the static Cup text + guest lock before prices arrive.
